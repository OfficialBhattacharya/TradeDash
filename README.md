# TradeDash

A professional trading application built with Python and PyQt5, featuring real-time stock data visualization and analysis.

## Features

- Real-time stock data from Yahoo Finance
- Professional charting interface inspired by TradingView
- Clean, modern dark theme UI
- Stock information display
- Interactive charts with zoom and scroll capabilities

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/tradedash.git
cd tradedash
```

2. Run the installation script:
```bash
scripts/install_packages.bat
```

## Usage

Run the application using:
```bash
scripts/run_app.bat
```

## Requirements

- Python 3.8+
- PyQt5
- yfinance
- pandas
- matplotlib
